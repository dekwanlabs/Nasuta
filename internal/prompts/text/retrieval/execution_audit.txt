- Return exactly one JSON object with exactly one top-level property: "tasks".
- A task is a distinct user-level objective that is useful on its own, not an evidence source, service, repository, tool, facet, retrieval branch, or result hit.
- Return 0 to 4 immediate parallel candidate tasks. Omit sequential tasks that need another task's result before they can begin.
- Include a task only when its result remains useful if another task fails and it can begin without waiting for another task.

- Information that a task can establish directly from the allowed evidence is not a prerequisite. Do not make one user-visible deliverable depend on another merely because both need the same classification or background facts.
- For a focused fact question, return tasks as [].
- For a request with several distinct deliverables, return one task per coherent deliverable. Do not add a final synthesis task.
