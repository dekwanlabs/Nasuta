# Flow: <Name from supplied content>

## Format

Each flow document covers one complete **business chain**, from
trigger to completion.

### Frontmatter (required)

```yaml
---
scope: event-driven                    # fixed value
tags: [flow, event-driven, troubleshooting, ...] # add only source-backed identifiers
---
```

### Title

`# Flow: <Name from supplied content>`

Use the source content's natural language. Do not require or invent a translated
second name.

### Required Sections (in order)

1. **Overview** (1-2 paragraphs) — what this chain does, which services it
   touches, and the business value.
2. **Trigger Sources** (`## Trigger Sources`) — table: Event | Trigger
   Service | Trigger Condition.
3. **Full Chain** (`## Full Chain`) — ASCII diagram or nested list, from
   trigger to terminal state.
4. **Key Services** (`## Key Services`) — table: Service | Responsibility |
   Data Store | Log/Search Index. Populate physical resource columns only when
   the supplied content names them verbatim; otherwise write `Not established
   from supplied content` in the source content's natural language.
5. **Troubleshooting** (`## Troubleshooting`) — table: Common Problem →
   Resolution Steps.
6. **Dependencies** (`## Dependencies`) — external services this chain
   depends on + who depends on this chain.

### Optional Sections

- **Data Storage** (`## Data Storage`) — table groups when multiple DBs.
- **Middleware** (`## Middleware`) — Kafka/RabbitMQ/Redis etc.
- **Branch Flows** (`## Branch Flows`) — alternative handling branches.

### Notes

- Do not add id or doc_id to frontmatter; the platform assigns the canonical document ID.
- Preserve service names, API paths, Feign interface names, data stores, and
  log/search indices exactly as supplied. This template has no codegraph or
  lookup capability, so never claim an external verification was performed.
- Prefer tables over prose. Troubleshooting steps must be supported by supplied
  operational content. Otherwise state what evidence must be collected; do not
  invent an index, keyword, dashboard, command, or endpoint.
- Cross-reference another document only when its exact filename is supplied.
